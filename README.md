# 🐍 Snake Game
 
This is a Snake game built using HTML, CSS, and JavaScript. It is a browser-based Snake Game inspired by the classic arcade game. The player controls a growing snake, collects food to increase their score, and must avoid colliding with the walls or their own body.

## 🎯 What Problem Does It Solve?

The project recreates a classic game in a web browser while providing a practical way to explore game logic, keyboard controls, collision detection, and dynamic UI updates.

## 💡 Why I Built It

I built this project to strengthen my JavaScript skills and get more comfortable with programming interactive applications.

It allowed me to take a familiar game concept and turn its rules into working code while learning how different parts of a game interact in real time.

## 🎮 Features
- Smooth keyboard controls
- Score tracking
- Increasing difficulty
- Clean, responsive UI

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 🧩 What I Struggled With

The most challenging part was implementing the snake movement and collision detection.

I had to keep track of the snake's position as it moved around the board and make sure the game correctly detected collisions with the walls, the snake's own body, and the food.

Managing the game loop and updating the screen continuously also helped me understand how real-time interactions work in JavaScript.

## 🚀 How to Run
1. Download or clone the repository
2. Open `index.html` in your browser
3. Start playing
